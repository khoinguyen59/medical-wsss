## 3. Quy Tac Bao Ve Git (`.gitignore`)
- Thu muc `repos/*` da duoc cau hinh trong `.gitignore` de khong commit cac thu vien con vao git chinh cua do an.
- Moi ma nguon tham khao deu co the duoc goi truc tiep tren dia cuc bo `repos/` ma khong lo xung dot submodule.
